# VE-08 — Startup Coordination & Seamless Activation
2026-11-24 17:09 +08:00

Baseline: local delivered Video Enhancement Consolidation (user reports working). No GitHub checkout or commit performed. Scope: improve the startup experience; no Adaptive Tone, UI changes, model changes, or alteration of the established B1/B2.1/B2.2/perceptual algorithms at full strength.

## Critical regression invariant (user clarification)
Window resize used to cause the **Ready Video Buffer to decline slowly to zero and then refill even after all window interaction had stopped**. This is NOT evidence of insufficient GPU throughput. Repeated fixes resolved it in the current baseline. Do not change its existing resize-only B08 bank-pressure escape, pending resize scheduling, 500 ms estimator settling guard, display-submit lead estimator, producer admission, buffer capacity/target or original-frame protection for optional enhancement. Treat any recurrence after adding a feature as a regression requiring investigation, not as expected startup behavior.

## Changes
- New `VideoEnhancementStartup.h`: cold startup guard checks existing extended startup and geometry status. On the completed running route require an already presented frame; only if actual MFG effective multiplier >=2 require 80 ms of contiguous ready reserve (or four ready frames with positive ready time). Bypass/legacy do not depend on a fixed water level. This gate governs optional VE only, until the first LUT activation of the segment; steady-state admission stays as before. A deliberately shallow running buffer can defer VE without blocking playback. No change to existing buffer capacity or recovery policy.
- Prepare thumbnail, fused perceptual, B2 fallback and standalone shaders in the existing model worker, with device-only operations. Publish immutable shader handles with existing Ready/Failed acquire/release state. No new threads or immediate context work on worker. Stop requests prevent further shader prep where cancellation is observed; existing fast-retirement path remains. Seek invalidates inference generation but can reuse shader preparation/model. A driver compilation or graph initialization already in progress may finish in retired worker; not a new caller-side wait.
- In the normal cold path, suppress perceptual-only preview until first valid LUT. Full model failure retains safe standalone fallback if prepared shader is available; no synchronous compile retry. Existing calibrated fallbacks remain.
- First successful LUT-bearing completed Present records media PTS in `RememberPresentedSvdLutB2`; legacy records first successful running LUT draw. Final fused result uses `smoothstep` over 250 ms media time (including preferred/skin), before dither. Fallback calibrated LUT paths use same activation through existing blend parameter. No sleep/timer/wait/new full-screen pass. First zero-alpha draw is still a valid LUT-bearing draw. Seek/flush/stop/toggle reset activation and old LUTs; resize alone does not. Pause/repaint of the same PTS does not advance it. Ordinary cuts continue B1 policy. In fallback-only failure case without any valid LUT, standalone effect may enter directly.
- Successfully pre-drawn completed image is cached regardless of whether a newer LUT might arrive before Present. Retry after actual draw failure/geometry invalidation/busy conditions remains existing policy. This removes unnecessary redraw solely for optional grade. Does not change fence ownership or PTS ordering.
- Legacy MFG source/generated tagging audit remains separate; this patch deliberately does not touch legacy MFG dispatch/metadata.
